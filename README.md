# MERN Stack Learning

A complete repository to learn the **MERN Stack** through a practical, hands-on approach. This repository focuses on building a strong foundation by combining concise explanations with coding exercises and real-world projects.

Whether you're a beginner or looking to revise concepts, the content is structured to help you learn by writing code instead of just reading theory.

## What You'll Learn

### Frontend
- HTML
- CSS
- JavaScript (ES6+)
- Responsive Design
- React.js
- React Router
- State Management

### Backend
- Node.js
- Express.js
- REST APIs
- Authentication & Authorization
- File Uploads
- Error Handling
- Middleware

### Database
- MongoDB
- Mongoose
- Database Design
- CRUD Operations

### Full Stack
- JWT Authentication
- MERN Project Structure
- Deployment
- Best Practices

## Learning Approach

Instead of long theoretical explanations, every topic follows this format:

1. Learn the concept
2. See an example
3. Practice with exercises
4. Solve challenges
5. Build a mini project

The goal is to spend more time coding than reading.

## How to Use

1. Clone the repository

```bash
git clone https://github.com/<your-username>/mern-learning.git
```

2. Open the topic you want to learn.

3. Read the notes.

4. Complete all practice questions before moving to the next topic.

5. Build the mini project for that section.
